# Mihajlo Raspopovic - Portfolio

Full Stack Developer & Graphic Designer portfolio website built with React, TypeScript, and Tailwind CSS.

## About

This is the personal portfolio website of Mihajlo Raspopovic, showcasing projects, designs, and professional experience in web development and graphic design.

## Features

- **Responsive Design**: Optimized for all devices
- **Dynamic Content**: Powered by Strapi CMS
- **Multilingual Support**: English and Serbian languages
- **Modern Tech Stack**: React, TypeScript, Vite, Tailwind CSS
- **Interactive UI**: Smooth animations and transitions
- **SEO Optimized**: Meta tags and structured data

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Radix UI
- **CMS**: Strapi (Headless CMS)
- **Deployment**: GitHub Pages
- **Icons**: Lucide React, React Icons

## Development

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/mihajloraspopovic/WebSitev2.git

# Navigate to project directory
cd WebSitev2

# Install dependencies
npm install

# Start development server
npm run dev
```

### Available Scripts
- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run deploy` - Deploy to GitHub Pages

## Deployment

The website is automatically deployed to GitHub Pages. To deploy changes:

```bash
npm run deploy
```
